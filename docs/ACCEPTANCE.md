## 准备与记录

1. 两台系统使用**同一个 ZIP**，比对 SHA-256。关闭其他晾图进程后开始。
2. 运行 `winver`，记录版本、版本类型、构建号；Win10 必须注明 22H2。记录显示器布局、主屏、缩放比例和任务栏位置。
3. 建立包含测试图片的专用目录，保留外部图片散列。不要使用生产截图或敏感剪贴板内容。
4. 用托盘设置选择该目录；先关闭剪贴板导入。数据/日志由设置入口打开。
5. CI 构建信息和系统证据作为附件保存；结果列填“通过 / 失败 / 未测”并附日志事件或截图。

```powershell
Get-FileHash -Algorithm SHA256 .\Shotline-1.0.0-win-x64.zip
Get-ComputerInfo | Select-Object WindowsProductName, WindowsVersion, OsBuildNumber, OsArchitecture
pwsh -NoProfile -File .\scripts\build.ps1 -DesktopTests
```

最后一条需要源码与 .NET 10 SDK，会改写剪贴板，并只对临时测试副本执行回收。纯便携包用户无需执行源码测试。
